# study-planner-mvp
Minimal MVP study planner for managing student tasks
## Problem
Students often struggle to organize assignments and deadlines in one clear place. This leads to missed deadlines, stress, and inefficient time management.

## Pitch
Study Planner is a simple tool for students that helps organize tasks and deadlines in one place. It allows users to quickly add assignments, view them in a list, and mark them as completed to reduce stress and improve productivity.

## Goal of the First Iteration
To create a working MVP that allows users to complete the main scenario: add a task, see it in the list, and mark it as completed.

## MVP (Core Value)
The minimal viable product includes:
- Adding a new task
- Displaying tasks in a list
- Marking tasks as completed

## Stakeholders
The primary stakeholder is the student user who receives value from better task organization. The developer is responsible for implementing the solution within time and resource limits. The instructor evaluates whether the project meets academic requirements.

## Success Criteria
- A user can add and complete a task in less than 30 seconds.
- The main scenario works without critical errors.
- A new user can understand how to use the application without instructions.
## User Scenario

**Precondition:** The user opens the Study Planner application.

**Steps:**
1. The user enters the task name in the input field.
2. The user clicks the "Add" button.
3. The task appears in the task list.
4. The user marks the task as completed.
5. The task changes its visual state (e.g., becomes crossed out).

**Expected Result:**
The task is successfully added to the list and can be marked as completed without errors.

## Acceptance Criteria

- The task appears in the list immediately after clicking the "Add" button.
- The task can be marked as completed with one click.
- The application does not crash during the main scenario.
- The full scenario can be completed in less than 30 seconds.

## Initial Feature List (First Increment)

- Task input field
- Add task button
- Task list display
- Mark task as completed
- Basic UI layout
